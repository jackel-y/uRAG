# Causal Inference DAG

## Project Overview

This repository hosts a tutorial in learning about Causal Inference DAG

* Source: https://towardsdatascience.com/a-simple-explanation-of-causal-inference-in-python-357509506f31/

## Key Features

* **Causal_DAG.ipynb:**
    * Application of causal inference DAG using *networkx, causalnex,* and *pgmpy*

## Getting Started

Follow these instructions to set up the project and run the forecasting system.

### Prerequisites

* Python 3.x (Python 3.9.6 recommended based on project)
* Git

### 1. Clone the Repository


git clone [https://github.com/jackel-y/causal-inference-dag.git](https://github.com/jackel-y/causal-inference-dag.git)

### 2. Set up the Virtual Environment
It's highly recommended to use a virtual environment to manage project dependencies.

### 3. Install Dependencies
Install the required Python packages:
pip install -r requirements.txt
